# ЛЮДИ / ГОРОД — MVP 0.1

Мобильный видеомаркетплейс впечатлений в Петербурге. 2 сценария: готовое впечатление и «Загадай впечатление». Вертикальные 9:16 истории, свайпы, поиск, профили-заглушки, избранное, заявки.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173).

## Бесплатное размещение GitHub Pages

1. Создайте новый репозиторий GitHub, загрузите туда содержимое проекта, ветка `main`.
2. В Settings → Pages → Build and deployment выберите **GitHub Actions**.
3. При push в `main` workflow `.github/workflows/deploy.yml` автоматически публикует сайт.
4. Сайт получит адрес вида `https://USER.github.io/REPO/`. Vite использует относительный `base`, поэтому корректно работает из папки репозитория.

## Заявки

По умолчанию приложение работает в ДЕМО-РЕЖИМЕ: заявки сохраняются только в `localStorage` конкретного браузера и **НЕ доставляются администратору**. Не рекламируйте такой режим как действующую услугу.

Чтобы включить серверное сохранение заявок, создайте проект на Supabase (учтите актуальные лимиты бесплатного тарифа), выполните `supabase.sql` в SQL Editor и добавьте следующие GitHub Actions variables (Settings → Secrets and variables → Actions → Variables):

- `VITE_SUPABASE_URL`: Project URL
- `VITE_SUPABASE_ANON_KEY`: public anon / publishable key, **НЕ `service_role`**

В локальной разработке скопируйте `.env.example` в `.env` и установите те же переменные. Пересоберите приложение. Заявки будут поступать в `public.requests` и будут видны только администратору в Supabase Dashboard. Нет публичного чтения.

**Важное ограничение:** публичная вставка без капчи уязвима к спаму. Для боевого запуска нужно добавить серверную антиспам-проверку и rate limiting, юридически корректную политику обработки данных, согласия, сроки хранения, сведения об операторе, договорные условия и способы связи с организаторами. Не публикуйте проект с реальными заявками, пока эти вопросы не решены.

## Контент и видео

Демо-контент в `src/main.jsx` → `programs`. Изображения — авторские SVG-заглушки в `public/`. Цены и организаторы вымышлены. Добавьте реальные вертикальные видео (MP4/H.264, 9:16) в `public/` и укажите в `programs` `video:'/имя-файла.mp4'`. Видео стартует без звука, воспроизводится циклически; пользователь может управлять звуком и паузой. Для больших видео позже лучше отдельное хранилище/CDN (GitHub Pages не рекомендован для больших видеокаталогов).

## Реклама блогеров

Ссылки с параметром `?utm_source=blogger_nickname` сохраняют источник в заявке. Чтобы измерять переходы и конверсии, добавьте аналитику и согласованный с правилами конфиденциальности трекинг. Привлечение блогеров по бартеру или комиссии не отменяет возможных требований к маркировке рекламы.
